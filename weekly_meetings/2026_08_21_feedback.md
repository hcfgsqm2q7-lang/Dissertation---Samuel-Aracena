## Main Research Question

I suggest framing the paper around:

> How do heterogeneous humanitarian data sources differ in their spatial and temporal coverage, granularity, missingness and measurement reliability when integrated into a common subnational framework?

This gives you three sub research questions:

1. *Where are the data gaps?* Which districts, periods and humanitarian mechanisms are well observed and which are poorly observed?
2. *Are these gaps systematic?* Do they depend on how the data are collected, for example through satellites, market surveys, event monitoring or humanitarian reporting?
3. *What do we gain by combining sources?* Which sources provide complementary information, and which add little beyond what is already available?

Food insecurity remains a useful application domain, but it does not need to become the main prediction task.

## Main Limitations

### 1. ReliefWeb geoparsing still needs proper validation

You correctly found that the original geoparsing method had low precision. This is an important result in itself because it shows that apparently simple geographic matching can create large errors. However, the improved geoparser still needs a proper final validation.

**What to do:** Create a new random sample of around 100–150 reports that you did not use while improving the system. For each report, manually identify:

- which districts are genuinely discussed;
- which districts are mentioned only in passing;
- whether no Admin-2 location can be identified.

Then compare the manual labels with the final automatic geoparser and report:

- precision;
- recall;
- F1;
- examples of false positives;
- examples of false negatives.

This validation should refer to the final geoparsing method, not the original one.

### 2. Be careful with the meaning of "coverage"

You made an important distinction between structural availability, recorded coverage and true observability. Keep this.

A value in the dataset does not automatically mean that reality has been fully observed. For example:

- ACLED zero means no recorded event, not necessarily no conflict;
- CHIRPS has broad spatial coverage, but this does not mean it perfectly measures every local condition;
- ReliefWeb coverage depends heavily on reporting attention and successful geographic extraction.

**What to do:** For every source, clearly document:

- how the data are collected;
- where the source can theoretically provide information;
- where values are actually available;
- what a zero means;
- what missing data mean;
- the main possible measurement biases.

This can become an important table in the dissertation.

### 3. The WFP data-quality issue must be resolved clearly

One of your strongest findings was that much of the WFP export appears to contain model-generated forecasts rather than observed prices. This is exactly the kind of issue this dissertation should highlight. However, before using the full-year 2024 market data, you need to explain exactly which values are observed and which are forecasts.

**What to do:** Create a simple month-by-month table showing:

- month;
- number of observed price records;
- number of forecast records;
- number of missing records.

Do not combine forecast prices with genuinely observed prices without clearly marking them. If reliable observed data exist only for January and February, say so explicitly. This is not a failure of the dissertation. It is an important result about the limitations of the source.

### 4. Some statistical tests need to account for repeated districts

You now have 12 observations for each district. These observations are not independent. For example, whether a district has a WFP-monitored market is mostly a district-level characteristic. Repeating the district over 12 months should not be treated as 12 independent pieces of evidence.

**What to do:** For variables that are fixed at district level, analyse them at district level. For monthly outcomes, such as whether a district receives ReliefWeb attention, use a model that accounts for repeated observations. A simple option is:

- logistic regression with district-clustered standard errors;
- or, mixed-effects logistic regression with district as a random effect (if you are comfortable implementing it).

Do not interpret smaller p-values caused only by having repeated monthly rows as stronger evidence.

### 5. The conflict-versus-climate result is interesting, but the wording is too strong

You found that relatively extreme conflict observations receive more humanitarian reporting than relatively extreme climate-stress observations. This is potentially a very interesting result about the data collection process. However, do not call the two groups "equally severe" or "comparable severity". Being in the worst 10% of two different variables does not mean that the humanitarian impact is equivalent.

**What to do:** Use wording such as: "*Reporting attention is higher during relatively extreme conflict observations than during relatively extreme climate-stress observations.*"

Then test whether the result is robust to different definitions of "extreme", for example: top 5%; top 10%; top 20%.

Also test the relationship continuously rather than relying only on thresholds. For example, check whether reporting increases as conflict intensity increases, and whether the same happens as climate stress increases.

### 6. Source complementarity needs to be measured directly

You already know that different sources have different coverage. The next important question is what combining them actually adds. Simply saying that the final dataset contains more information is not enough.

**What to do:** For every district-month, calculate how many humanitarian mechanisms are observed:

- conflict available?
- climate available?
- market available?
- reporting available?

Then calculate:

- percentage of district-months with 1 mechanism observed;
- percentage with 2;
- percentage with 3;
- percentage with all 4.

Also calculate each source's unique contribution. For example: *How many district-months gain an additional observed mechanism when WFP is added?* This provides a simple and strong measure of complementarity.

### 7. Do not turn the project into a prediction study

You previously proposed comparing the integrated dataset with IPC. That could become a large additional project involving prediction models, train/test splits, evaluation metrics and many extra methodological choices. That is not necessary for this dissertation.

**What to do:** Keep IPC, if useful, as contextual information or as an external descriptive comparison. For example, you may show whether poorly covered districts are also districts experiencing serious food insecurity.

But do not make food-insecurity prediction the main contribution. Your contribution should remain focused on what we learn about humanitarian data collection itself.
